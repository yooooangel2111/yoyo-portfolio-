# yoyo 李宇宥 Portfolio

個人作品集網站（純 HTML / CSS / JavaScript，無需安裝）。

## 上線方式（GitHub Pages）
1. 建立公開 repository，名稱 `你的帳號.github.io`
2. 把這個資料夾「裡面」的所有檔案上傳到 repository 根目錄（index.html 要在最外層）
3. Settings → Pages → Branch 選 `main`、資料夾 `/ (root)` → Save
4. 等 1–2 分鐘，打開 `https://你的帳號.github.io/`

## 修改文字
在網址後面加 `?edit`（或直接在電腦上開 index.html），右下角會出現編輯工具列。改完按「導出 HTML」，把下載的檔案改名為 index.html 重新上傳。
